# Product and quality metrics

| Metric | Definition | MVP target |
|---|---|---:|
| Design completion | Designs passing all blocking preflight checks | ≥ 90% after one revision |
| Decision reproducibility | Same input produces the same recommendation | 100% |
| Policy-case accuracy | Reference cases with expected recommendation | 100% |
| Invalid readout interception | Seeded SRM/peeking/immaturity cases caught | 100% |
| Evidence coverage | Recommendation reasons backed by computed checks | 100% |
| Time to design | Median time from hypothesis entry to launch-ready plan | < 10 min |

No LLM fluency metric can substitute for statistical correctness. Future generative explanations should be evaluated for factual consistency against the deterministic result object, unsupported claims, and actionability.
